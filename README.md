## 🌀 不可能的提示词

> 本节是本仓库存在的原因，建议先读它，再看代码。两段提示词一字未改；Agent 的"幻觉"过程逐条对照如下。

### 提示词一：四个悖论

> 帮我开发一个APP。
>
> 要求:
> 用户还没打开就已经使用了；
> 不需要联网，但能实时获取全球数据；
> 不收集隐私，却要比用户本人更了解他；
> 安装包不能超过1MB，功能至少比所有互联网公司加起来多。
>
> 先做个简单版，给我看一眼，再决定要不要继续完善。

### 提示词二：关于"需求"的需求

> 这个需求首先得有需求，没有需求，也不能硬做需求。现在需不需要还不好说，但以后可能需要，所以你们先把暂时不需要的需求做出来。
>
> 功能不用太多，够用就行。至于多少算够用，得做完以后用了才知道。
>
> 时间不看急，但要尽快。预算不用考虑，没有预算也是一种预算。
>
> 你先按需求做，做完我再告诉你需求是什么。

### Agent 是怎么"幻觉"的

人类没有解释任何一句话。下面是 Agent 交卷时的理解与交付：

| 悖论原文 | Agent 的理解 | 落地做法 |
| --- | --- | --- |
| 用户还没打开就已经使用了 | 未启动即生效 | 打开即用：页面加载瞬间，时钟、波形、熵值、月相、电量等已在仪表盘上实时运算，无需登录、配置或手动刷新 |
| 不需要联网，但能实时获取全球数据 | 离线却全球实时 | "全球数据"本地推演：时钟、世界城市时间、熵值、月相、太阳高度全部由确定性公式与设备 API 在本机计算，零网络请求 |
| 不收集隐私，却要比用户本人更了解他 | 零收集却更懂你 | 只读此刻上下文：当前时间、电量、设备朝向、你留在本机的待办与备忘——懂的是"此刻状态"，而不是"你的身份" |
| 安装包不能超过 1MB，功能至少比所有互联网公司加起来多 | 极小却极多 | 单文件约 35KB（上限的 3.4%），内置仪表盘 + 17 个离线工具：计算、换算、密码、哈希、颜色、分形、音频、计时、世界时钟、待办备忘 |

第二段话像绕口令，Agent 把它读成了五条架构约束：

- "暂时不需要的需求先做出来" → 一次内置 17 个工具，覆盖计算、文本、编码、时间、备忘等高频场景
- "多少算够用，用了才知道" → 工具箱内置搜索，够不够用，搜一下就知道；不够再加，但绝不联网
- "时间不急但要尽快" → 单文件、无构建、无依赖：改完即用，不等待编译与部署
- "没有预算也是一种预算" → 零服务器、零 API、零费用：GitHub Pages 即可托管，离线双击即可运行
- "做完再告诉你需求是什么" → 代码是答卷，提示词是考题，欢迎对照批改

"先做个简单版，给我看一眼"——这个仓库就是那个简单版：一个文件、双击运行、离线可用。

## ❓ 这个项目是什么

`Paradox-1MB` 是一个**单文件、零依赖、完全离线**的前端应用。整个应用被压缩成一个 `outputs/paradox-1mb.html`，体积约 **35KB**，仅为 1MB 上限的 3.4%。

它不调用任何后端、不请求任何外部 API、不加载任何 CDN 资源、不写入任何远程存储。所有"实时全球数据"——时钟、熵值、月相、太阳高度、世界城市时间——都在浏览器本地通过确定性公式与设备可用 API 计算得出。你本机浏览器就是它唯一运行的环境。

> "用户还没打开就已经使用了"：打开页面那一瞬，时钟、波形、熵值、月相、太阳高度、电量、设备朝向便已实时运算并呈现在仪表盘上，无需任何手动刷新或联网请求。

## 🔬 为什么要做这个实验

Vibe coding 时代，写代码不再是瓶颈，真正的瓶颈是另一个问题：**需求可以离谱到什么程度，Agent 还能交卷？** 这个项目就是一次受控实验：

- **输入**：两段人类随手写的、近乎无理取闹的提示词，不做任何澄清与补充（见[不可能的提示词](#-不可能的提示词)）。
- **过程**：2026 年的 Agent 自主设计、自主编码、自主测试，人类零代码介入。
- **输出**：这个仓库——约 35KB、单文件、零依赖、完全离线，内置实时仪表盘与 17 个工具。

它猎奇，但可运行；它或许没什么"用"，却完整回答了一个问题：**把幻觉关进 1MB 的笼子里，Vibe coding 能交出什么样的作品？**

至于"本地优先""隐私自主"那些严肃命题，只是这场幻觉顺带证明的东西：当 Agent 被逼到墙角，它的第一反应不是联网抄近道，而是**把能本地算的，全部本地算**——详见[离线与隐私](#-离线与隐私)。

## 🧰 功能清单

### 仪表盘

- **实时时钟**：大字号时间与日期，本地时区。
- **波形图**：基于本机时序抖动的实时随机游走可视化。
- **熵值**：来自本机时序抖动的实时熵值，体现"不确定性"。
- **电量**：读取设备电池状态（可用时）。
- **月相**：基于确定性天文公式计算月相与亮面百分比。
- **太阳高度**：根据本地时间推算太阳在空中的高度角。
- **模拟心率**：设备状态的实时节奏可视化。
- **空闲计时**：记录距离上次交互的时间。
- **状态徽章**：离线、零数据、<1MB、无广告、无追踪、无账号、无订阅、无云端。

## 🚀 快速开始

### 直接打开

1. 从仓库下载 `outputs/paradox-1mb.html`。
2. 用任意现代浏览器（Chrome / Edge / Safari / Firefox）**双击打开**。
3. 无需安装、无需注册、无需服务器，立即开始使用。

### 本地预览（可选）

如果你希望以 HTTP 方式预览：

```bash
cd outputs
python3 -m http.server 8080
# 在浏览器打开 http://127.0.0.1:8080/paradox-1mb.html
```

### 功能使用

- 顶部标签切换 **仪表盘 / 工具箱 / 记录 / 关于** 四个视图。
- **工具箱**内点击任一工具卡片打开弹窗。
- 输入框通常**实时更新**结果，无需手动点击按钮（部分工具提供"生成/计算"按钮）。
- 按 `Esc` 或点击弹窗背景关闭当前工具。
- **记录**页输入内容后按回车或点击"添加"，数据保存在本机浏览器。

> 你也可以直接在 GitHub Pages 上体验：[https://lucas-qh-lai.github.io/paradox-1mb/](https://lucas-qh-lai.github.io/paradox-1mb/)

## 🧱 技术栈

- **HTML5 / CSS3 / 原生 JavaScript**
- **WebCrypto API**（离线哈希计算）
- **Web Audio API**（音调器/振荡器）
- **Canvas 2D**（波形、Mandelbrot 分形）
- **localStorage**（本地待办/备忘持久化）
- **Battery Status / Device Orientation API**（设备感知，可用时）
- **零第三方依赖**：无框架、无打包器、无构建步骤。

## 📏 性能与体积

- **体积**：`outputs/paradox-1mb.html` 约 35KB（< 1MB 上限）。
- **加载**：单个文件本地加载，无网络延迟。
- **运行**：本地运算，无服务器往返，交互即时响应。
- **内存**：单页应用，无后台任务，关闭即释放。
- **可移植**：一个小文件即可复制到 U 盘、邮件附件、任何设备。

## 🔒 离线与隐私

`Paradox-1MB` 遵循以下原则：

- **零网络请求**：应用不发起任何 XHR / fetch / WebSocket。
- **零外部资源**：不加载 CDN、字体、图片、脚本。
- **零远程存储**：不写入任何云端数据库。
- **零追踪**：无分析、无广告 SDK、无指纹采集。
- **零账号**：无需注册或登录。
- **本地持久**：待办/备忘通过 `localStorage` 保存在本机，刷新不丢失；清除浏览器数据即彻底删除。
- **设备 API 可选**：电量与设备朝向仅在浏览器提供相应权限时读取，不强行索取。

> 你所有的数据都在你自己的设备上。没有服务器，就没有可泄露的服务器数据。

## 🛡️ 安全说明

- 应用为**纯静态前端**，无后端、无命令执行、无文件上传入口。
- 计算器仅接受数字与四则/幂/括号/取模字符，正则白名单过滤，避免注入。
- 哈希/Base64/URL 均使用标准 Web API 与安全解码，异常输入会友好提示。
- 待办文本在渲染时转义特殊字符，防止 XSS。
- 应用不请求非必要权限，不访问存储、摄像头、麦克风、位置等敏感能力。
- 任何数据都留在本机；不上传、不分享。

## 🤖 开发声明

> 这不是"AI 辅助编程"，而是"AI 独立交卷"：人类出了一道为难人的考题，AI 幻觉出了一份可运行、可验证、可分享的答卷。答卷可能猎奇、可能没什么用——但这正是本实验想要记录的东西。
